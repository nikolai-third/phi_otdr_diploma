\begin{frame}[t]{Введение и обзор литературы}
    \footnotesize
    \begin{itemize}
        \item Оптическая рефлектометрия восстанавливает распределение обратного сигнала вдоль волокна по времени прихода рассеянного излучения.
        \item Физическая основа сигнала - \textbf{обратное Рэлеевское рассеяние} на случайных микронеоднородностях стекла.
        \item В классическом OTDR обычно анализируется усреднённый профиль мощности, поэтому для повышения отношения сигнал/шум требуется накопление большого числа трасс.
        \item В \textbf{phase-sensitive OTDR} используется когерентное зондирование: вклады обратного Рэлеевского рассеяния интерферируют, а внешнее воздействие меняет их относительные фазы.
        \item Поэтому информативными становятся изменения уже \textbf{между соседними рефлектограммами}; на практике для устойчивой автоматической локализации удобно использовать короткие окна из десятков или сотен трасс, а не только усреднённый профиль линии.
    \end{itemize}

    \vspace{0.4ex}
    \begin{alertblock}{Сложность задачи на длинных линиях с усилителями}
        \small
        Большой объём данных, неоднородный профиль линии и слабый локальный контраст в raw waterfall делают ручной анализ ненадёжным. Поэтому нужен автоматический алгоритм: парсинг, выравнивание, подавление фона и локализация возмущений.
    \end{alertblock}
\end{frame}

\begin{frame}{Цель и задачи исследования}
    \begin{block}{Цель}
        Разработать воспроизводимый метод обработки данных phi-OTDR, который позволяет автоматически выделять рефлектограммы из непрерывного сигнала, повышать интерпретируемость измерений и локализовать возмущения вдоль волоконной линии.
    \end{block}

    \vspace{0.5ex}
    \begin{itemize}
        \item Построить парсер, который сам определяет начала и длину рефлектограмм без внешней разметки.
        \item Перевести данные в физически интерпретируемое представление расстояние - время.
        \item Исследовать спектральные и робастные методы выделения возмущений.
        \item Проверить работу метода на реальных данных с известными зонами воздействия.
    \end{itemize}
\end{frame}

\begin{frame}[t]{Алгоритм детекции: идея и математическая схема}
    \begin{center}
        \resizebox{0.96\textwidth}{!}{
            \begin{tikzpicture}[
                node distance=0.55cm,
                block/.style={draw=phiBlue, rounded corners=2pt, fill=phiBlue!7, align=center, minimum width=2.3cm, minimum height=0.95cm},
                arrow/.style={-{Latex[length=2mm]}, thick, draw=phiBlue}
            ]
                \node[block] (a) {Aligned\\reflectograms};
                \node[block, right=of a] (b) {Median\\background};
                \node[block, right=of b] (c) {Residual\\signal};
                \node[block, right=of c] (d) {MAD\\normalization};
                \node[block, right=of d] (e) {FFT-based\\features};
                \node[block, right=of e] (f) {Combined\\score + peaks};

                \draw[arrow] (a) -- (b);
                \draw[arrow] (b) -- (c);
                \draw[arrow] (c) -- (d);
                \draw[arrow] (d) -- (e);
                \draw[arrow] (e) -- (f);
            \end{tikzpicture}
        }
    \end{center}

    \vspace{0.2ex}
    \begin{block}{Робастная предобработка}
        \small
        \[
            b(x)=\operatorname{med}_t I(x,t), \qquad
            r(x,t)=I(x,t)-b(x)
        \]
        \[
            s(x)=1.4826 \cdot \operatorname{med}_t \left| r(x,t)-\operatorname{med}_t r(x,t)\right|, \qquad
            z(x,t)=\frac{r(x,t)}{s(x)+\varepsilon}
        \]
    \end{block}

    \small
    \begin{itemize}
        \item $b(x)$ выделяет \textbf{стационарный профиль линии}: затухание, усилители, устойчивые отражающие участки.
        \item $r(x,t)$ убирает постоянный фон и оставляет только отклонения относительно типичной рефлектограммы.
        \item $s(x)$ задаёт \textbf{робастный масштаб} по расстоянию, а $z(x,t)$ становится входом для частотных и энергетических признаков.
    \end{itemize}
\end{frame}

\begin{frame}[t]{Алгоритм детекции: фон и нормировка}
    \begin{columns}[T,onlytextwidth]
        \column{0.64\textwidth}
        \includegraphics[width=\linewidth,height=0.39\textheight,keepaspectratio]{detect_step_background.png}

        \vspace{0.4ex}
        \includegraphics[width=\linewidth,height=0.39\textheight,keepaspectratio]{detect_step_mad_profile.png}

        \column{0.36\textwidth}
        {\footnotesize
        \textbf{Что происходит на этом этапе}
        \begin{itemize}
            \item Медианный фон $b(x)$ описывает устойчивую форму линии как функцию расстояния.
            \item MAD-масштаб показывает, где естественный разброс по времени велик, а где мал.
            \item После нормировки сравнивается не абсолютная яркость, а статистически значимое отклонение.
        \end{itemize}

        \vspace{0.2ex}
        \textbf{Робастная нормировка}
        \[
            z(x,t)=\frac{I(x,t)-\operatorname{med}_t I(x,t)}{1.4826\operatorname{MAD}_t(r)+\varepsilon}.
        \]
        }
    \end{columns}
\end{frame}

    \vspace{0.5ex}
    {\scriptsize
    \textbf{Преимущества предлагаемого подхода}
    \begin{itemize}
        \item Спектральная информация всё ещё извлекается из всей записи, но в качестве конечного результата сохраняется не полная двумерная карта, а только \textbf{одномерный score по расстоянию}.
        \item Это упрощает хранение, последующий анализ и автоматическое принятие решения: вместо time-frequency heatmap нужно рассматривать только один профиль вдоль линии.
        \item В отличие от классического OTDR здесь сохраняется фазовая интерференционная динамика соседних трасс, поэтому информативны уже короткие окна измерения.
    \end{itemize}
    }
\end{frame}

\begin{frame}{Выводы}
    \begin{itemize}
        \item Разработан робастный алгоритм детекции возмущений в данных phi-OTDR, ориентированный на длинные волоконные линии с усилителями и неоднородным фоном по расстоянию.
        \item Ключевое преимущество метода - свёртка time-frequency информации в \textbf{одномерный score по расстоянию}, который существенно проще анализировать, чем двумерные спектральные карты.
        \item По памяти и по интерпретации такой подход выгоднее полного time-frequency анализа: хранится и анализируется линия признака, а не тепловая карта.
        \item Метод сохраняет чувствительность уже на \textbf{коротких окнах порядка 0.1 с}: этого достаточно, чтобы просканировать линию длиной порядка 60 км и выделить основные зоны воздействия.
        \item На контрольном эксперименте автоматически локализованы две основные зоны возмущения около 31.7 км и 42.6 км.
        \item Дальнейшее развитие работы - стабилизация парсинга на длинных записях и расширение валидации на сценарии нагрева и механического воздействия.
    \end{itemize}
\end{frame}
