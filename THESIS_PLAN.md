# План доведения работы до бакалаврского диплома

Дата составления: 2026-05-08

Этот документ — рабочий план **под написание текста ВКР** (20–25 страниц) от текущего состояния репозитория. Цель чисто научная: получить числа и графики, которых не хватает для диплома. Развитие кода после защиты не планируется, поэтому всё, что не идёт в текст или презентацию (рефакторинг, тесты, CI, абстракции «на будущее»), вне области этого плана.

---

## 1. Где мы сейчас

### Сделано
- **Инфраструктура:** воспроизводимый pipeline (`audit → index → baseline → artifacts`), checkpoint/resume, локальный кэш под WebDAV — этого более чем достаточно
- **Аудит датасета:** 50 файлов через baseline (35 ok / 15 err), таблицы и summary
- **Парсер рефлектограмм (массово):** 552 файла с USB прошли парсер, **453 ok (82 %)** в `data/processed_usb/parser_cache/`. Это сильно больше, чем видно из `summary_baseline.md` — массовая обработка фактически сделана
- **Пост-детекция (точечно):** работает; на эталоне `2024-10-11_18_59` находит **31.736 км / 42.600 км** при ожидаемых ~32 / ~42 км — попадание сотни метров на 60-километровой линии
- **Презентация на 11 слайдов** + 29 ассетов в `slides/assets/` — готовый скелет для текста
- **Апробация:** выступление на конференции уже было (вписать какой именно во введение)

### Главный неиспользованный ресурс — `data_for_ml/`
В `data/raw_usb/data_for_ml/data_description.json` лежит **labeled ground truth**:
- 130 описаний, **92 файла с `event=1`** (известна истинная зона воздействия)
- зоны: `(1100,1300)`, `(1300,1400)`, `(1460,1600)`, `(2300,2400)` — индексы distance-bin
- 4 линии (`id_line` ∈ {1,2,3,4}), 5 длительностей импульса (100/200/300/500/1000 нс)

**Этот датасет ни разу не пропускался через детектор.** Прогон по нему — единственная вещь, которая отделяет работу «работает на одном файле» от работы с настоящими цифрами precision / recall / F1 в тексте диплома.

## 3. Структура ВКР: 20–25 страниц (без приложений)

Объём 20 страниц упомянут в правилах ЛФИ; Положение МФТИ даёт «рекомендуемые 30–40», но локальные правила физтех-школы важнее. Ориентир — 20–25, конкретно подтвердить у научрука.

```
Титульный лист           — 1 стр (формируется в личном кабинете)
Аннотация                — 1 стр (≤ 1500 знаков)
Содержание               — 1 стр

ВВЕДЕНИЕ                 — 1.5–2 стр
  актуальность · объект/предмет · цель · задачи · методы ·
  значимость · апробация (конференция уже была — указать какая, дата, доклад)

ГЛАВА 1. φ-OTDR и обзор методов детекции возмущений             — 3–4 стр
  1.1 Принцип φ-OTDR, обратное Рэлеевское рассеяние, особенности
      длинных линий с усилителями (неоднородный фон)
  1.2 Существующие методы (CWT, wavelet packet, matrix matching —
      сжатая таблица из slide 263)
  1.3 Постановка задачи

ГЛАВА 2. Данные                                                 — 2–3 стр
  2.1 Установка (рисунок `phi_otdr_scheme.pdf`), параметры регистрации
      (Fs=50 МГц, импульсы 100–1000 нс, длина линии)
  2.2 Состав датасета и размеченный набор `data_for_ml`
      (статистика, появляется из P0-3)

ГЛАВА 3. Метод                                                  — 5–6 стр
  3.1 Парсер: детекция стартов, авто-период, восстановление пропусков,
      cross-correlation alignment (формулы из README, метрики
      coverage_ratio и residual jitter)
  3.2 Робастный фон по времени (median) → residual → MAD-нормировка
  3.3 Спектральные признаки (peak, broadband) и комбинированный score
  3.4 Псевдокод и параметры по умолчанию

ГЛАВА 4. Результаты                                             — 5–6 стр
  4.1 Качество парсинга на 552 файлах (P0-3)
  4.2 Контрольный кейс 2024-10-11_18_59: 31.736 / 42.600 км
      (текущий сильный результат, картинки уже есть)
  4.3 Метрики на data_for_ml (P0-1) — precision, recall, F1,
      ошибка локализации, зависимости от импульса и линии
  4.4 Сравнение с энергетическим baseline (P1-4)
  4.5 Ограничение метода на 10-секундных записях (P0-2)
  4.6 [опц.] Абляции (P1-5)

ЗАКЛЮЧЕНИЕ              — 1 стр
  итоги по задачам · практические рекомендации · план дальнейших
  исследований (ОБЯЗАТЕЛЬНО для бакалаврской по Положению МФТИ)

СПИСОК ИСТОЧНИКОВ       — 1 стр
  4 статьи из таблицы сравнения + φ-OTDR обзор + ГОСТы
```

Грубый итог: ~22 страницы основного текста. Есть запас в обе стороны.

### Оформление (Положение МФТИ, Приложение 2)
- A4, поля 30/15/20/20 мм
- Times New Roman, 12–14 pt, 1.5 интервал, абзац 1.25 см, по ширине
- Нумерация со 2-й стр. (титул не нумеруется)
- Рисунки: «Рисунок N — Название» **под** рисунком, по центру
- Таблицы: «Таблица N — Название» **над** таблицей, слева
- Оригинальность ≥ **70 %** (Антиплагиат)

## 8. Один абзац для научрука (актуально на 9 мая)

> Метрики на размеченном датасете получены. На 92 positive + 38 negative
> файлах из `data_for_ml/` предложенный детектор (combined: 0.55·peak +
> 0.30·broad + 0.15·energy с двойным порогом) даёт **F1 = 0.476**
> (recall 0.38, precision 0.64) при медианной ошибке локализации **61 м**.
> Энергетический baseline уступает на 14 пунктов F1 (0.33), peak-only —
> на 5 пунктов (0.43) при втрое большем числе ложных срабатываний.
> Recall ограничен ~0.47 для top-usable независимо от порога: 1-секундные
> записи дают Δf ≈ 1 Гц, поэтому шаги 0.57 Гц неразрешимы спектрально и
> детектор работает только по широкополосным импактам. Этого достаточно,
> чтобы написать главу «Результаты» с таблицей сравнения и зависимостями
> по pulse duration / id_line. Все числа лежат в `reports/`,
> воспроизводятся одним прогоном `scripts/evaluate_detector.py`.
