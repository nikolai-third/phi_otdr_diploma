## 1. ВВЕДЕНИЕ (1.5–2 страницы)

### Что писать

- **Актуальность.** φ-OTDR как распределённый акустический сенсор; применения: мониторинг трубопроводов, охрана периметра, сейсмика, мониторинг ж/д путей. Особый интерес — длинные (десятки–сотни км) линии с EDFA-усилителями [1, 4, 5]. На таких линиях сигнал затухает, и фон становится сильно неоднородным; ручной анализ ненадёжен, нужен автоматический алгоритм.
- **Объект исследования:** временные ряды φ-OTDR — массивы [N_traces × N_distance_bins] от длинной линии (≥ 60 км).
- **Предмет:** алгоритмы обработки этих рядов для автоматической локализации воздействий.
- **Цель работы.** Разработать воспроизводимый метод обработки данных φ-OTDR, который автоматически выделяет рефлектограммы из непрерывного сигнала, выравнивает их и локализует возмущения на длинной линии с неоднородным фоном.
- **Задачи** (нумерованный список из 5 пунктов — точно как в задачах из приказа об образовательном стандарте):
  1. Анализ существующих подходов к локализации возмущений в φ-OTDR.
  2. Программная реализация парсера, выделяющего отдельные рефлектограммы из непрерывного сигнала АЦП.
  3. Кросс-корреляционное выравнивание трасс с критериями приёма.
  4. Робастный детектор возмущений на основе медианного фона, MAD-нормировки и спектральных признаков.

- **Методы исследования.** Робастная статистика (медиана, MAD); кросс-корреляционный анализ; спектральный анализ (FFT); метрики precision / recall / F1 / median localization error.

## 2. ОБЗОР ЛИТЕРАТУРЫ И ПОСТАНОВКА ЗАДАЧИ (4–5 страниц)

### 2.1 Принцип φ-OTDR (≈ 1 страница)

- Когерентное обратное Рэлеевское рассеяние; в отличие от классического OTDR измеряется не средняя мощность, а интерференция [1, 3].
- Связь времени прихода и расстояния: `x = c·t / (2·n)`, где n ≈ 1.468 для одномодового волокна на 1550 нм.
- Чувствительность к деформации волокна → возмущения видны как изменение фазы между соседними трассами.
- **Рисунок 1.** Схема установки φ-OTDR (использовать готовый `phi_otdr_scheme.pdf` из `slides/assets/`).
- **Рисунок 2.** Пример одной рефлектограммы (`single_reflectogram_example.png`).
- Цитировать: [1] Lu 2019, [2] Palmieri 2013, [3] Lu 2010 (базовая работа по phase-OTDR).

### 2.2 Особенности длинных линий с усилителями (≈ 0.5–0.7 страницы)

- Затухание ~0.2 дБ/км → 60 км линия даёт >12 дБ ослабления.
- EDFA-усилители частично компенсируют, но добавляют ASE-шум; в результате фон по distance сильно неоднороден.
- Простой энергетический детектор тонет в этом фоне (это потом подтвердится в результатах: F1 = 0.33 у energy-only).
- Цитировать: [4] Peng 2014 (128 км с EDFA), [5] Wang 2016, [6] обзор по distributed amplification.

### 2.3 Существующие методы локализации возмущений (≈ 2 страницы)

Сделать как в дипломе Сенокосова (раздел «Сравнение с подходами из литературы») — таблица из 4 строк. Этот раздел уже частично написан в `slides/presentation_phi_otdr.tex` (frame `Сравнение с подходами из литературы`), берём оттуда.

- **2.3.1 Continuous wavelet transform** — Qin, Chen, Bao [9]. CWT scalogram → wavelet ridge → global wavelet spectrum → location. Хорошо работает на нестационарных вибрациях, но требует полного time-frequency анализа и продемонстрирован на коротких линиях.
- **2.3.2 Wavelet packet decomposition** — [10] Optik 2014. Энергии пакетов → выделение возмущённых зон. Устойчив к дрейфу частоты лазера, но даёт энергетическую карту, а не компактный score.
- **2.3.3 Data Matrix Matching** — Liu et al. [11] Sensors 2018. Real-time, отклик 50 мс. Построен под конкретную acquisition-схему и короткую линию (1.2 км); неоднородный фон длинной линии не центральная проблема.
- **2.3.4 ML-методы (CNN/RNN)** — [12, 13]. Высокая точность на event classification, но требуют большой размеченный набор и не дают физической интерпретации.
- **Таблица 1.** Сравнение четырёх подходов: «Алгоритм / Применимость / Размер выходного результата / Ограничения». Использовать таблицу из slide 263 презентации.

### 2.4 Постановка задачи (≈ 0.5 страницы)

Зафиксировать пробел: **существующие методы плохо адаптированы к длинным линиям с сильно неоднородным фоном и обычно выдают 2D time-frequency результат вместо компактного location-score**. Сформулировать требования к разрабатываемому методу:
1. Робастность к затуханию вдоль линии (учёт distance-зависимости фона).
2. Независимость от знания конкретной частоты воздействия.
3. Компактный 1D-результат по distance, а не 2D-карта.
4. Валидация на размеченном наборе данных (precision / recall / F1).

### 3.2 Парсер: выделение рефлектограмм (≈ 1.5 страницы)

Это «инфраструктурный» раздел — описать кратко, чтобы перейти к более содержательным шагам. Можно адаптировать раздел из README (он уже хорошо структурирован).

- Задача: из непрерывной записи `x[n]`, `n = 0..N-1` выделить отдельные рефлектограммы фиксированной длины `L_hat`.
- **Шаг 1.** Прореживание + скользящее среднее + экспоненциальные огибающие (формулы из README, секция «Математическая схема парсера»).
- **Шаг 2.** Детекция кандидатов стартов: робастный динамический диапазон, пороги по уровню и по градиенту. Ключевые формулы:
  - `Δ = Q98(m) - Q02(m)` (робастный размах)
  - `θ_low = Q02(m) + β_low · Δ`, `θ_rise = β_rise · Δ`
  - кандидат: `m[k-1] < θ_low` и `g[k] > θ_rise`
- **Шаг 3.** Авто-оценка периода через гистограмму гармоник + голоса с весом `1/√k`.
- **Шаг 4.** Восстановление пропущенных стартов между «якорями» (формулы из README).
- **Метрика качества:** `coverage_ratio = n_extracted / expected_traces`.
- **Рисунок 3.** Иллюстрация работы парсера: исходный сигнал + детектированные старты (использовать `parser_2024-10-11_19_08_full/измерение_возмущение__...__raw_segment.png`, после перегенерации).

### 3.3 Кросс-корреляционное выравнивание (≈ 0.7 страницы)

- Задача: межтрассовый jitter (различные подсэмпловые сдвиги) портит FFT по времени.
- Алгоритм: парные сдвиги в окне `[a, a+W]`, регуляризация (медианная нормализация дрейфа), интегрирование в абсолютные сдвиги `s_i`.
- Применение `aligned[i, :] = shift(traces[i, :], -s_i)`.
- Принятие решения: **alignment применяется только если улучшилось хотя бы одно из трёх**: mean residual ≤ 0.92·before; p95 residual ≤ 0.70·before AND std не выросло >5 %; row-to-row roughness q99 ≤ 0.90·before. **Рисунок 4.** Waterfall до и после выравнивания (готовые `waterfall_before_2024_10_11_18_59.png`, `aligned_waterfall_presentation.png` из `slides/assets/`).

### 3.4 Робастный детектор возмущений (≈ 2 страницы)

Самый содержательный раздел. Шесть шагов с формулами и пояснениями.

- **Step 1: медианный фон по времени.** `B(d) = median_t aligned[t, d]`; `R[t, d] = aligned - B`. Идея: медиана робастна к импульсным выбросам (ударам от шагов), фоновый профиль линии стабилен.
- **Step 2: MAD-нормировка по distance bin.** `scale(d) = MAD_t R[t, d]`; `z[t, d] = R / scale`. После этого шаги в местах активного возмущения становятся z-score 5–10, а спокойные участки — околонулевыми.
- **Step 3: группировка bins (group_bins = 20) и FFT по времени.**
  - `grouped(t, g) = mean_{d ∈ group_g} z[t, d]`
  - `P(f, g) = |FFT_t grouped|² → 10·log₁₀ P (dB)`
- **Step 4: per-frequency robust baseline.**
  - `row_med(f) = median_g P(f, g)`; `row_mad(f) = MAD_g P(f, g)`
  - `zf(f, g) = (P - row_med) / row_mad`
- **Step 5: одномерный score по distance.**
  - `peak(g) = max_f zf(f, g)` — самый яркий частотный пик
  - `broad(g) = mean_f max(0, zf(f, g) - 1)` — широкополосная активность
  - `energy_z(g) = (RMS_t grouped(g) - median) / MAD`
  - **Combined score:** `S(g) = 0.55·peak + 0.30·broad + 0.15·energy_z`
- **Step 6: пороговый отбор + non-maximum suppression.**
  - `combined_thr = median(S) + 3·MAD(S)`
  - `peak_thr = median(peak) + 5·MAD(peak)` (двойной gate)
  - кандидат: `peak ≥ peak_thr` И `S ≥ combined_thr` И `ignore_start ≤ d ≤ usable_end`
  - подавление повторов: минимальное расстояние между детекциями `min_sep_km = 2.0`
- **Рисунок 5.** Шаги детектора (готовые `detect_step_*.png` из `slides/assets/`).
- Веса 0.55/0.30/0.15 подобраны эмпирически; в разделе 4.4 будет показано, что замена их на одну компоненту существенно ухудшает F1.
- Цитировать: [14] Hoaglin для MAD, [15] Huber для робастной статистики.

### 4.5 Ограничения метода (≈ 0.7 страницы)

- **Recall плато ~0.47 на top-usable.** Для половины файлов настоящая зона воздействия даёт меньший combined-score, чем какой-то другой участок линии. Причина: в 1-секундных записях Δf ≈ 1 Гц, поэтому шаги 0.57 Гц неразрешимы спектрально, и детектор работает только по широкополосным импактам (~5–100 Гц), которые слабее самого периодического воздействия.
- **10-секундные записи: пустой пороговый детект.** На длинных непрерывных записях фон уплывает по времени; стационарная медиана-MAD перестаёт быть хорошей моделью. Возможное решение — скользящая нормировка по сегментам ~1 с (направление дальнейших работ).
- **Pulse duration 100 нс / 1000 нс.** Короткий — слабый сигнал; длинный — размытие зоны воздействия по distance, peak score падает.
- **Negatives только из одной линии.** 38 размеченных negatives — все из id_line=3, импульс 500 нс. Precision = 0.636 — оценка сверху; на репрезентативном negative-наборе будет ниже.

## 5. ЗАКЛЮЧЕНИЕ (≈ 1 страница)

Структура — точно в соответствии с задачами из введения:

1. **Выполнен анализ методов локализации возмущений в φ-OTDR.** Установлено, что существующие подходы (CWT, wavelet packet, matrix matching) либо требуют полного time-frequency анализа, либо ориентированы на короткие линии и не учитывают неоднородность фона на длинных линиях с усилителями.
2. **Реализован парсер,** автоматически выделяющий рефлектограммы из непрерывного сигнала АЦП. На 552 файлах достигнут coverage_ratio 100 % при 96.9 % успехе на дататсете.
3. **Реализовано кросс-корреляционное выравнивание трасс** с робастными критериями приёма; среднее остаточное джиттер-смещение 0–1 точки на чистых записях.
4. **Разработан робастный детектор** на основе медианного фона, MAD-нормировки и комбинированного спектрального score.
5. **Метод валидирован на 130 размеченных файлах:** F1 = 0.48, медианная ошибка локализации 61 м. Сравнение с одно-компонентными baseline-детекторами (energy_only F1 = 0.33, peak_only F1 = 0.43) подтверждает, что **спектральные признаки в сочетании с MAD-нормировкой существенно улучшают точность по сравнению с простым энергетическим методом**.

**Практическая значимость:** метод даёт компактный 1D-score по расстоянию, что упрощает интерпретацию и хранение. Применим к данным φ-OTDR на длинных линиях с EDFA-усилителями.

**Дальнейшие направления исследований** (обязательный пункт для бакалаврской — Приложение 1 п.1 Положения МФТИ):
- Скользящая по времени нормировка для устойчивой работы на 10-секундных записях.
- Расширение валидационного набора на разные линии и условия (репрезентативные negatives).
- Адаптивный выбор group_bins под пространственное разрешение каждой линии.
